Eliminación de datos de usuario

Cómo borrar los datos de Calendario WoodTools y quitarle el acceso a tus cuentas.

Aplicación: Calendario WoodTools · Última actualización: 15 de septiembre de 2026

No hay copias en servidores. Calendario WoodTools guarda todo en la computadora donde está instalada. WoodTools no tiene servidores con datos de tus cuentas, así que no hace falta enviar ninguna solicitud: con los pasos de esta página se borra todo. Si necesitás ayuda, escribinos a la dirección de contacto que figura al pie.

1. Qué datos guarda la Aplicación

  • Conexiones: tokens de acceso de Facebook, Instagram, Threads, YouTube y TikTok, y datos básicos de cada cuenta (nombre, ID, nombre de usuario o nombre del canal).
  • Tareas y contenido: tareas, textos, links, ajustes de publicación y copias de las imágenes y videos elegidos.
  • Configuración: identificadores de las apps de desarrollador de WoodTools y datos de su cuenta de Cloudinary.
  • Estado: resultado de las publicaciones y estado de las conexiones (sin tokens).
  • Sesión de inicio de sesión: las cookies de Facebook, Instagram y Threads que guarda la ventana de inicio de sesión de la Aplicación.

Todo está en el perfil de Windows del usuario, en %APPDATA%\calendario-interactive y %LOCALAPPDATA%\CalendarioWoodTools.

2. Desconectar una red

  1. Abrí Calendario WoodTools.
  2. Entrá a ⚙ Conexiones y elegí la red.
  3. Tocá Desconectar. Los tokens de esa red se borran en el momento.

Los identificadores de la app de desarrollador y la sesión de la ventana de inicio de sesión de Facebook, Instagram y Threads quedan guardados para poder volver a conectar. Para borrarlos también, seguí el punto 3.

3. Borrar todos los datos

  1. Cerrá la Aplicación: clic derecho en su ícono de la bandeja del sistema (al lado del reloj) → Salir.
  2. Desinstalala: Configuración de Windows → Aplicaciones → Aplicaciones instaladas (en Windows 10: Aplicaciones y características) → Calendario WoodTools → Desinstalar.
  3. Apretá Windows + R, escribí %APPDATA% y tocá Aceptar. Borrá la carpeta calendario-interactive.
  4. Apretá Windows + R, escribí %LOCALAPPDATA% y tocá Aceptar. Borrá la carpeta CalendarioWoodTools.
  5. Vaciá la Papelera de reciclaje.

4. Quitar el acceso en cada plataforma

Borrar los datos en la computadora no le quita el permiso a la Aplicación en tus cuentas. Para hacerlo:

  • Google / YouTube: security.google.com/settings/security/permissions → Calendario WoodTools → Quitar acceso.
  • Facebook: Configuración y privacidad → Configuración → Integraciones comerciales → Calendario WoodTools → Eliminar.
  • Instagram: Configuración → Permisos del sitio web → Apps y sitios web (o Integraciones comerciales) → Calendario WoodTools → Eliminar.
  • Threads: Configuración → Cuenta → Permisos del sitio web → Calendario WoodTools → Eliminar.
  • TikTok: Perfil → menú → Configuración y privacidad → Seguridad y permisos → Administrar apps → Calendario WoodTools → Eliminar acceso.

5. Archivos en Cloudinary

Las fotos y videos para Instagram, Threads e historias de Facebook se suben a la cuenta de Cloudinary de WoodTools. Para borrarlos: Media Library → carpeta calendario-wt → seleccioná los archivos → Delete.

6. Publicaciones ya realizadas

Lo que ya se publicó sigue en cada red. Para eliminarlo, borralo desde Facebook, Instagram, Threads, YouTube Studio o TikTok.

7. Plazos

  • Al tocar Desconectar o al borrar las carpetas, los datos se eliminan en el momento.
  • Si quitás el acceso desde la plataforma (punto 4), la Aplicación deja de poder usarlo y elimina los tokens y datos de esa cuenta dentro de los 7 días.
