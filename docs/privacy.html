Política de privacidad

Qué datos usa Calendario WoodTools, para qué, dónde se guardan, con quién se comparten y cómo eliminarlos.

Aplicación: Calendario WoodTools · Última actualización: 15 de septiembre de 2026

Calendario WoodTools (la «Aplicación») es una aplicación de escritorio para Windows de WoodTools. La usa el equipo de WoodTools para organizar tareas y publicar el contenido de la empresa en sus propias cuentas de Facebook, Instagram, Threads, YouTube y TikTok. Esta política explica qué datos obtiene la Aplicación, para qué los usa, dónde los guarda, con quién los comparte y cómo se eliminan. Al conectar una cuenta o usar la Aplicación, aceptás esta política.

1. Resumen

  • La Aplicación accede solo a lo necesario para publicar el contenido propio de WoodTools en sus propias cuentas.
  • Todo se guarda en la computadora donde está instalada. WoodTools no tiene servidores que reciban esos datos.
  • No vendemos ni compartimos datos, y no hay publicidad ni analíticas.
  • Podés desconectar las cuentas y borrar todo en cualquier momento (ver Eliminación de datos).

2. Datos a los que accede la Aplicación

2.1 Datos que carga el equipo

  • Tareas: títulos, notas, fechas, horarios, nivel de importancia, recurrencia y plantillas.
  • Contenido a publicar: textos, links, ajustes de cada red y los archivos elegidos (imágenes y videos). La Aplicación guarda una copia de cada archivo en su carpeta.
  • Configuración: los identificadores de las apps de desarrollador de WoodTools en cada plataforma y los datos de su cuenta de Cloudinary (nombre de la nube y del upload preset).
  • Resultados: el ID, el enlace o el error de cada publicación.

2.3 Lo que la Aplicación no hace

  • No ve ni guarda contraseñas: cada inicio de sesión se hace en la página oficial de la plataforma.
  • No lee mensajes, comentarios, seguidores, contactos, estadísticas ni datos de cuentas de otras personas.
  • No accede al correo, a Drive ni a otros servicios de la cuenta de Google.
  • No usa la cámara, el micrófono ni la ubicación.

3. Cómo usamos los datos

Usamos los datos exclusivamente para:

  • publicar el contenido que el equipo programó, en las cuentas de WoodTools, en el momento indicado;
  • mostrar el estado de cada conexión y avisar cuando haya que reconectar;
  • renovar automáticamente los accesos para que las publicaciones programadas no fallen.

La Aplicación no publica nada que el usuario no haya programado o enviado con «Publicar ahora». Los datos no se usan para publicidad, perfiles de usuarios ni entrenamiento de modelos de inteligencia artificial, y no se venden.

4. Dónde se guardan

  • Solo en la computadora donde está instalada la Aplicación, dentro del perfil de Windows del usuario:
    • %APPDATA%\calendario-interactive: tareas, copias de los archivos, configuración, credenciales de conexión y sus copias de respaldo.
    • %LOCALAPPDATA%\CalendarioWoodTools: copia de respaldo de las credenciales de conexión.
  • Esas carpetas están protegidas por los permisos de Windows: solo esa cuenta de usuario y los administradores de la computadora pueden leerlas. Recomendamos usar la Aplicación en una cuenta de Windows con contraseña y no copiar esos archivos a otros lugares.
  • Cookies y datos en el dispositivo: la ventana de inicio de sesión de Facebook, Instagram y Threads guarda las cookies de sesión de esas plataformas dentro de %APPDATA%\calendario-interactive, para no pedir el inicio de sesión cada vez. Google y TikTok usan el navegador del sistema, con sus propias cookies. La Aplicación no usa cookies propias, identificadores publicitarios ni herramientas de analítica, y este sitio web tampoco.
  • WoodTools no tiene servidores que reciban o guarden estos datos. El sitio calendario-woodtools.onrender.com es informativo; su página de retorno del inicio de sesión solo muestra un mensaje y no guarda ningún dato.

5. Con quién se comparten

  • Con la plataforma de destino, solo al publicar o conectar: el contenido y los datos necesarios se envían a la API oficial de la red elegida, que los trata según su propia política: Política de privacidad de Meta (Facebook, Instagram y Threads), Política de Privacidad de Google (YouTube) y Política de privacidad de TikTok.
  • Cloudinary: las fotos y videos para Instagram, Threads e historias de Facebook se suben a la cuenta de Cloudinary de WoodTools para que Meta pueda descargarlos. Se trata del mismo contenido que se va a publicar. Ver la política de privacidad de Cloudinary.
  • Nadie más. No vendemos, alquilamos ni cedemos datos a terceros, salvo que una ley o una autoridad competente lo exija.

6. Servicios de API de YouTube y Google

  • La Aplicación usa los Servicios de API de YouTube para subir videos al canal de WoodTools. Al usar las funciones de YouTube, aceptás las Condiciones del Servicio de YouTube.
  • Los datos obtenidos mediante los Servicios de API de YouTube también quedan alcanzados por la Política de Privacidad de Google (http://www.google.com/policies/privacy).
  • El uso y la transferencia de la información recibida de las API de Google cumplen la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.
  • Podés quitarle a la Aplicación el acceso a tu cuenta de Google en cualquier momento desde https://security.google.com/settings/security/permissions.

7. Conservación y eliminación

  • Tokens y datos de las cuentas: se conservan mientras la cuenta está conectada. La Aplicación los renueva y actualiza automáticamente; los datos obtenidos de las API se actualizan o se eliminan dentro de los 30 días.
  • Desconectar: al tocar «Desconectar» en la sección Conexiones, los tokens de esa red se borran en el momento.
  • Acceso revocado: si quitás el acceso desde la plataforma, la Aplicación deja de poder usarlo y elimina los tokens y datos de esa cuenta dentro de los 7 días.
  • Tareas y archivos: se conservan hasta que el usuario los borra o desinstala la Aplicación y elimina sus carpetas.
  • Archivos en Cloudinary: se alojan solo para que las redes los descarguen, y WoodTools los elimina periódicamente de su cuenta de Cloudinary.

Los pasos para borrar todo están en Eliminación de datos.

8. Cómo quitar el acceso

  • En la Aplicación: Conexiones → elegí la red → Desconectar.
  • Google / YouTube: security.google.com/settings/security/permissions → Calendario WoodTools → Quitar acceso.
  • Facebook: Configuración y privacidad → Configuración → Integraciones comerciales → Calendario WoodTools → Eliminar.
  • Instagram: Configuración → Permisos del sitio web → Apps y sitios web (o Integraciones comerciales) → Calendario WoodTools → Eliminar.
  • Threads: Configuración → Cuenta → Permisos del sitio web → Calendario WoodTools → Eliminar.
  • TikTok: Perfil → menú → Configuración y privacidad → Seguridad y permisos → Administrar apps → Calendario WoodTools → Eliminar acceso.

9. Seguridad

  • Las cuentas se conectan con los inicios de sesión oficiales (OAuth) de cada plataforma. Google y TikTok se abren en el navegador del sistema, con verificación de estado y PKCE.
  • Toda comunicación con las APIs se hace por HTTPS.
  • La Aplicación no escribe tokens ni claves en sus registros.

10. Menores de edad

La Aplicación es una herramienta de trabajo para el equipo de WoodTools y no está dirigida a menores de 18 años.

11. Cambios a esta política

Si cambiamos esta política, publicaremos la nueva versión en esta página con su fecha de actualización.
